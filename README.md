# Video Player with Discord Recording

Приложение для воспроизведения видео с автоматической записью веб-камеры и отправкой в Discord.

## 🚀 Функции

- **Воспроизведение видео** в полноэкранном режиме
- **Автоматическая запись** веб-камеры при просмотре
- **Отправка записанного видео** в Discord через webhook
- **Ограничение размера файла** до 20 МБ (настраиваемо)
- **Интерфейс статуса записи** с прогресс-баром
- **Поддержка разных браузеров** (Chrome, Firefox, Edge)

## ⚙️ Настройка

### 1. Discord Webhook

1. Создайте канал на Discord сервере
2. Настройки канала → Интеграции → Вебхуки
3. Создайте новый вебхук и скопируйте URL
4. Вставьте URL в `.env` файл:

```env
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/ваш_вебхук
```

### 2. Конфигурация

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Редактируйте `.env` файл:

```env
# Discord Webhook Configuration
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/ваш_вебхук

# Recording Settings
MAX_FILE_SIZE_MB=20          # Максимальный размер файла в МБ
VIDEO_QUALITY=720p          # Качество видео (360p, 480p, 720p, 1080p)
VIDEO_FPS=30                # Кадров в секунду
AUDIO_BITRATE=128000        # Битрейт аудио
VIDEO_BITRATE=2500000       # Битрейт видео

# Application Settings
ENABLE_DEBUG=true           # Включить отладку в консоли
AUTO_SEND=true             # Автоматическая отправка при достижении лимита
RECORD_ON_PLAY=true        # Запись при запуске видео
```

## 🖥️ Использование

1. Откройте `index.html` в браузере
2. Нажмите кнопку "Смотреть видео"
3. Разрешите доступ к камере и микрофону
4. Видео начнет воспроизводиться в полноэкранном режиме
5. Начнется запись веб-камеры
6. Прогресс-бар покажет заполнение до 20 МБ
7. При достижении 20 МБ видео автоматически отправится в Discord

## 🔧 Технические детали

### Поддерживаемые браузеры

- **Chrome 58+** (полная поддержка)
- **Firefox 53+** (полная поддержка)
- **Edge 79+** (полная поддержка)
- **Safari 14.1+** (ограниченная поддержка)

### Формат записи

- **Контейнер:** WebM
- **Видео кодек:** VP9
- **Аудио кодек:** Opus
- **Разрешение:** Настраиваемое (по умолчанию 720p)
- **Битрейт:** Настраиваемый (по умолчанию 2.5 Мбит/с)

### Логика работы

1. Пользователь нажимает "Смотреть видео"
2. Запрашивается доступ к камере и микрофону
3. Запускается видео в полноэкранном режиме
4. Начин��ется запись веб-камеры
5. Прогресс-бар отслеживает размер записи
6. При достижении 20 МБ запись останавливается
7. Видео отправляется в Discord через webhook
8. Пользователь получает уведомление

## ⚠️ Важные замечания

### Безопасность

- **Discord webhook URL** должен быть защищен (не публиковать в открытом доступе)
- **Доступ к камере** требует разрешения пользователя
- **HTTPS обязателен** для работы getUserMedia()

### Ограничения

- **Размер файла:** ограничен 20 МБ (настраивается)
- **Время записи:** зависит от качества и битрейта
- **Дисковое пространство:** запись хранится только в памяти браузера

### Проблемы и решения

| Проблема | Решение |
|----------|---------|
| "Не удалось получить доступ к камере" | Проверьте разрешения браузера |
| "Discord webhook не отвечает" | Проверьте URL и права вебхука |
| "Видео не отправляется" | Проверьте размер файла (<25 МБ для Discord) |
| "Ошибка MediaRecorder" | Обновите браузер до последней версии |
